# Interdato · Portafolio de Visión IA Industrial

Repositorio para GitHub Pages con un portafolio interactivo de visión artificial aplicada a industria, seguridad, almacén y retail.

## URL esperada

https://interdato.github.io/Deteccion-CamarasIA/

## Qué incluye

- Validación de EPP.
- Alertamiento automático.
- Zonas de riesgo.
- Inventario visual en racks industriales con estados lleno, hay espacio y vacío.
- Ergonomía y postura, incluyendo alerta por brazos por encima de hombros.
- Detección de comportamientos de riesgo de robo.
- Luces de seguridad en planta para grúas, montacargas, pasillos, perímetros y operación nocturna.
- Material comercial descargable en PDF y QR para compartir el portafolio.

## Edición rápida

- Textos de la página: editar `index.html`.
- Estilos visuales: editar `styles.css`.
- Interacciones: editar `script.js`.
- Videos: reemplazar archivos en `assets/videos/` manteniendo el mismo nombre.
- Posters e imágenes: reemplazar archivos en `assets/images/` manteniendo el mismo nombre.
- Material comercial: editar `assets/docs/portafolio-seguridad-ia-luces-interdato.html` y regenerar el PDF.

# Interdato · Portafolio de Visión IA Industrial

## URL público

https://interdato.github.io/Deteccion-CamarasIA/

Sitio estático para presentar demos comerciales de visión artificial aplicada a industria, seguridad, almacén y retail.

Incluye validación de EPP, alertamiento automático, zonas de riesgo, inventario visual en racks, ergonomía y detección de comportamientos de riesgo de robo.
